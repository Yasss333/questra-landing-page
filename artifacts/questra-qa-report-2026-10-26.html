Empty academic selectionsPaper assembly no longer falls back to Data Structures outside an empty selection.

Outcome selection event lifetimeCapture the chosen outcome before the React state updater runs.

Invalid draft submissionsQuestion and paper editors provide visible feedback for whitespace-only titles/answers; master-record names reject whitespace-only values.
Spreadsheet exportsCSV quotes/multiline fields are escaped and formula-like text is neutralized while numeric values stay numeric.

Browser coverage completed

  • Public-page matrix: widths 320, 360, 390, 430, 768, 820, 1024, 1280, 1440, and 1920 in light and dark themes; 844 × 390 phone landscape
  • All eleven dashboard modules and eight Master Data tabs at 390, 820, and 1440 in both themes; page overflow, image loading, visible text, and accessible control names
  • Desktop dropdowns and mobile navigation: outside click, Escape, arrow keys, breakpoint changes, touch taps, FAQ keyboard/touch interaction, skip link, and unobscured section links
  • Actual browser touch events horizontally swipe the phone table; tabs scroll, dialogs fit, and the modal keeps the background still
  • Theme persistence, unavailable browser storage, missing View Transitions API, animated transition cleanup, moving-grid pointer response, and reduced-motion preference
  • Academic filters, searches, pagination reset, no-result states, whitespace rejection, long/Unicode input, safe text rendering, and CSV escaping/formula neutralization
  • Question draft creation and review → approval → release → withdrawal; student demo shows released questions only
  • Paper assembly → faculty review → moderation → approval → immutable locking; review comments, audit history, and bank edits cannot alter the locked snapshot
  • Staff and outcome mapping, student profile edits, duplicate review, heatmap drill-down, report preview/download/history, reset and reload behavior
  • 110 rapid module transitions, four simultaneous isolated browser contexts, a working 404 recovery link, zero uncaught page exceptions, and zero HTTP 5xx responses
  • Enquiry required fields, malformed email, whitespace, encoded draft contents, and clearing stale prepared drafts. No email was sent

Two verified UI defects were corrected during this browser pass: pagination now resets when filters change, and nested editor dialogs preserve and restore focus to their original opener. The affected stateful workflows were rerun on the final production build, with eight further width/theme dialog regressions. Earlier failure screenshots and the initial result snapshot remain as historical debugging evidence; the result files listed below contain the final passing state.
